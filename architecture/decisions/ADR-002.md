# Approval and execution require a trusted baseline

## Decision and rationale

This authority boundary applies to the optional governed v2 workflow. ADR-005
defines the default advisory context and task-authorized verification path.

Candidate code and candidate architectural intent cannot approve one another. Guard compares a separately supplied reviewed model before executing commands. Unknown and not-executed results block a gate. The operator selects a reviewed Git SHA locally. Reviewer authentication and merge control remain external to v1; they do not require a repository host.

## Alternatives
Duplicated authority or implicit approval would obscure review and evidence boundaries.
