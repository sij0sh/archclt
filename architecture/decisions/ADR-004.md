# The package root is a shared bootstrap surface

## Decision and rationale
`src/archctl/__init__.py` carries package identity only. Every component that imports any
submodule also imports the package root, so eight component-to-package relationships are
declared as structural bootstrap edges. They are not feature dependencies and they do not
weaken the independence rules in ADR-001: Core still imports no feature module, Atlas still
imports no Guard, and Observatory still imports no Guard.

An import inside one component is not a relationship between components. Intra-component
observations are reported as ignored by reconciliation and never as undeclared drift.

## Consequences
A new component that imports a submodule declares its own bootstrap relationship. A component
that must not touch the package root cannot be expressed as an ordinary component.

## Alternatives
Declaring the bootstrap edges only to silence reconciliation would hide a structural fact.
Ignoring package-root observations without a decision would make the rule invisible to review.
