# Context and reasoning are the default

## Decision and rationale
Supply evidence, architectural reasons and execution outcomes for the coding
agent's decisions without requiring an approved model or acceptance baseline.
The user chose an implicit workflow alongside Briefcase to reduce the maintenance
of permission maps and architecture approval. Keep generated relationships and
recorded interpretations separate; preserve origin and source references.

Core owns immutable memory and optional identity overrides. Atlas assembles
bounded context. CLI composes features. Integrations share one bounded command
executor. Independent verification uses task authorization and source identity;
it does not invoke architecture authority comparison.

## Compatibility
ADR-002 continues to govern the optional v2 gate and its reviewed commands.
Neither context generation nor an ordinary command result claims approval under
that workflow. Existing gate semantics and negative regressions remain intact.

## Alternatives
Making all existing gates advisory would blur their guarantees and still fail to
retain architectural reasons. Duplicating source analysis would compete with
Briefcase rather than improve retrieval. A separate LLM service would add another
system to operate when the coding agent already supplies semantic judgment.
